# Optisol Global — Industrial Oils & VCI Export Packaging Website

A single-page corporate website for **Optisol Global**, Ahmedabad, India. Built with plain HTML, CSS, and JavaScript so it can be copied and pasted into any static hosting setup.

## Files included

- `public/website/index.html` — full page structure and content
- `public/website/styles.css` — responsive styling, navy + gold branding, animations
- `public/website/script.js` — mobile menu, sticky nav, scroll reveals, number counters, form validation

## How to use

1. Copy the contents of `index.html`, `styles.css`, and `script.js`.
2. Paste them into three files in your website folder: `index.html`, `styles.css`, and `script.js`.
3. Make sure the CSS and JS file paths in `index.html` match your folder structure:
   ```html
   <link rel="stylesheet" href="styles.css" />
   <script src="script.js"></script>
   ```
4. Open `index.html` in a browser or upload the folder to any static host.
