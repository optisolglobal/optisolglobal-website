## 📦 Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/optisolglobal/optisolglobal-website.git
```

2. Navigate to the project directory:
```bash
cd optisolglobal-website
```

3. Open `index.html` in your web browser or use a local server:
```bash
python -m http.server 8000
# or
npx http-server
```

## 🚀 Deployment

This website is deployed on **Cloudflare Workers**. To deploy your changes:

1. Make changes locally
2. Commit and push to GitHub
3. Cloudflare Workers will automatically deploy (if configured)
